# Homebrew WAVEIX Packages

Homebrew formulae that allows installation of WAVEIX packages through the [Homebrew](https://brew.sh/) package manager.

## Usage

```shell
brew tap waveix/pkg
brew install waveix/pkg/<name>
```

## Formulas

| Package                                          | Install                           | Description                     | Formula                         |
|--------------------------------------------------|-----------------------------------|---------------------------------|---------------------------------|
| [ffagent](https://gitlab.com/waveix/pkg-ffagent) | `brew install waveix/pkg/ffagent` | Toolkit for Agents based on LLM | [formula](./Formula/ffagent.rb) |
